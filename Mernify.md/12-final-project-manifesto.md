# 12 — Final Project Manifesto

**Status:** Supreme governing standard  
**Scope:** Entire Mernify digital presence  
**Conflict rule:** This manifesto overrides convenience whenever craftsmanship and speed disagree.

---

## What this project is

This is no longer a normal website.

**It is Mernify’s flagship digital product.**

Every decision — product, design, motion, engineering, content, and asset selection — must be made through the lens of **craftsmanship**.

The objective is **not** to finish quickly.  
The objective is to build a website **people remember**.

---

## Intentionality requirement

Every page, component, animation, interaction, image, icon, typography choice, spacing decision, and transition must feel intentional.

If something exists only because it was easy, fashionable, or “good enough,” it does not ship.

---

## Quality standards

| Standard | Meaning |
|----------|---------|
| Handcrafted components | No theme kits, no generic UI dumps |
| Meaningful animation | Motion clarifies hierarchy or story — never decoration for its own sake |
| Story-supporting transitions | Seams between sections continue the narrative |
| Rewarding interactions | Hover, focus, press, and magnetic feedback feel precise |
| Trust-strengthening imagery | Authentic, premium, product-relevant visuals only |
| Consistent icons | One family, one stroke language |
| Breathing layouts | Generous, confident whitespace — not emptiness from motion theater |
| Clear business purpose | Every section earns its place commercially |

---

## Forbidden feelings

The site must **never** feel:

- AI generated  
- Template based  
- ThemeForest inspired  
- Generic SaaS  
- Generic software house  
- Overdesigned  
- Empty because of excessive animations  

---

## Required feelings

The site must feel:

- Premium  
- Modern  
- Calm  
- Confident  
- Original  
- Engineered  
- Trustworthy  
- Fast  
- Elegant  

---

## References

References (Cuberto, Narsun, Elytra, tkxel, SSI, Digital Minds, Apple/Stripe/Linear/Vercel/Framer caliber) exist only to calibrate **quality and craftsmanship**.

**Never** recreate another company’s layout or visual identity.  
**Never** reuse their copyrighted assets.

---

## Five-year test

If any completed section does not feel worthy of representing Mernify for the **next five years**, redesign it before presenting it.

This test applies before self-review sign-off and before asking the user to approve the next section.

---

## Hierarchy of truth

When documents conflict, resolve in this order:

1. **This manifesto** (craftsmanship over convenience)  
2. Brand Guidelines + Brand Board + `06-brand-source-of-truth.md`  
3. `11-asset-and-content-policy.md`  
4. Creative Direction (`07`) + Homepage Spec (`08`)  
5. Self-Review Gate (`09`)  
6. Architecture / engineering docs  

---

## Operating oath

> Always prefer craftsmanship over speed.  
> This manifesto overrides convenience whenever there is a conflict.

---

*End of Final Project Manifesto.*
