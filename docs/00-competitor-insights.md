## Pattern Insights (Translate, Don’t Clone)

### UX
- Premium sites reduce choice: one primary CTA, one secondary.
- Trust appears early but quietly (logos / ratings), then deepens mid-page.
- Process is linear and scannable (3–5 steps, not 8).

### Visual hierarchy
- Brand / product name must dominate first viewport.
- One headline, one supporting line, one CTA group.
- Secondary content starts after the fold.

### Typography
- Competitors mix display + clean sans; Mernify needs expressive, non-default fonts (no Inter/Roboto/Arial/system as brand voice).

### Motion
- Scroll-linked reveals, staggered text, sticky storytelling work when tied to content.
- Avoid perpetual parallax noise and autoplaying marketing videos without control.

### Hero
- Full-bleed atmospheric plane (3D / cinematic image / abstract product field).
- No floating badges, promo chips, or stats in the hero.

### Navigation
- Compact primary nav; services as intentional destinations, not mega-menus of everything.
- Persistent but restrained contact CTA.

### Cards
- Use only for interactive containers (work items, selectable services).
- Prefer editorial layouts over card grids.

### CTA strategy
- Primary: Start a project / Book a call  
- Secondary: View work / Explore services  
- Soft mid-page CTAs after proof sections  

### Trust
- Client marks → case outcomes → testimonials → metrics (in that order of credibility).

### Portfolio
- Case studies as stories (problem → approach → outcome), not logo walls of screenshots.

### Performance
- Immersive sites often overspend on WebGL/video. Mernify must budget GPU and JS carefully (see Performance Strategy).

## Mernify Original Design Language — Positioning

**Name of language:** *Precision Atmosphere*

| Axis | Direction |
|------|-----------|
| Mood | Calm confidence, engineered clarity, quiet spectacle |
| Density | Generous whitespace; intentional tension, not emptiness |
| Depth | Soft atmospheric depth + precise UI edges |
| Motion | Kinetic typography + scroll choreography + restrained 3D |
| References (feel only) | Apple restraint · Stripe clarity · Linear precision · Vercel speed · Framer craft · Narsun ambition · Elytra immersion |

**Anti-references:** Purple SaaS gradients · cream/serif terracotta templates · newspaper broadsheet layouts · generic agency card farms · neon glow stacks · rounded-full pill clusters.
